# Product

merfolk is a canvas diagramming tool (Excalidraw/Miro-like) built around foldable, drill-down diagrams that round-trip with Mermaid.

- Groups are nodes with children; they fold/unfold like origami sheets, arbitrary depth.
- Mermaid source and canvas stay in sync live; the Tree panel mirrors subgraph nesting.
- Diagrams autosave to localStorage and export as `.merfolk.json`.
- Hand-drawn look via roughjs; dark/light themes via CSS variables.
